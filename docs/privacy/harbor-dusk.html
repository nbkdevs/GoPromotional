Harbor Dusk privacy policy

Applies to the Harbor Dusk browser theme for Google Chrome and Firefox. Effective 19 October 2026.

Summary: Harbor Dusk is a photographic dusk harbour theme. It contains only colours and images. It collects no data, stores no data and requests no permissions.

What the theme contains

The theme package holds a manifest with colour values and a few image files (the new tab background and toolbar artwork). It contains no JavaScript or other executable code, so it cannot read pages, track activity or make network requests.

Data we collect

None. The theme does not collect, store, transmit, sell or share any personal or non-personal data. There is no analytics, advertising or tracking of any kind.

Local storage

The theme stores nothing itself. Your browser keeps a record of which theme you have installed as part of its normal settings; that record stays in your browser and is handled under your browser’s own privacy policy.

Permissions

None. Browser themes cannot request extension permissions.

External link

The store listing for this theme links to branded merchandise. The theme itself shows no links. If you visit that website, it is governed by its own privacy and cookie policies, not this one.

Removing the theme

Switch back to the default theme in your browser settings (Chrome: Settings → Appearance → Reset to default; Firefox: Add-ons and themes → Themes) or uninstall it. No data is left behind.

Changes to this policy

If this ever changes, this page will be updated first and the effective date above will change.
