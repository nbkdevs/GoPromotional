# Agent skills

Each folder holds a `SKILL.md` (Agent Skills format) that lets an AI agent run one of the GoPromotional tools through `npx`.

| Skill | What it does | Website |
| --- | --- | --- |
| [gopromotional-event-planner](gopromotional-event-planner/SKILL.md) | Event countdown, planning timeline, giveaway quantities and print order-by dates. | [branded merchandise](https://www.gopromotional.co.uk/) |
| [gopromotional-siplog](gopromotional-siplog/SKILL.md) | Daily water goal estimate and a simple hydration log with streaks. | [branded water bottles for event marketing](https://www.gopromotional.co.uk/branded-products/branded-water-bottles) |
| [gopromotional-packlist](gopromotional-packlist/SKILL.md) | Packing checklists with templates, per-night quantities and a Markdown format. | [branded tote bags for event marketing](https://www.gopromotional.co.uk/branded-products/tote-bags) |
| [gopromotional-mugday](gopromotional-mugday/SKILL.md) | Caffeine tracker with half-life estimate, sleep-ready time and reusable-cup stats. | [branded travel mugs for event marketing](https://www.gopromotional.co.uk/branded-products/travel-mugs) |

Install one with any skills-compatible client, for example `npx skills add https://github.com/nbkdevs/GoPromotional --skill gopromotional-siplog`, or copy the folder into your agent's skills directory.
