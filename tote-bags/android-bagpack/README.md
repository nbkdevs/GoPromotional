# BagPack

Offline packing lists for events, errands, and days out. Tick items as they go into your bag.

## Features

- Create blank lists or use templates (conference, grocery, day out)
- Add / tick / delete items
- Progress count (packed vs total)
- Local Room persistence

Looking for a sturdy giveaway bag? See [branded tote bags for event marketing](https://www.gopromotional.co.uk/branded-products/tote-bags).

## Build

```bash
cd tote-bags/android-bagpack
./gradlew assembleRelease bundleRelease
```

Package ID: `uk.co.softrank.bagpack`
