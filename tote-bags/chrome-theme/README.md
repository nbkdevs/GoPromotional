# Canvas Trail — Chrome theme

Photographic golden-hour trail theme: warm grass, soft hills, and open sky.

Manifest V3 theme-only package (no extension icons or scripts).

## Package contents
- `manifest.json` — theme definition only
- `images/theme_ntp_background.png` — 1920×1080 photographic new tab art
- `images/theme_frame.png` / `theme_toolbar.png` — chrome strips
- `images/store_screenshot.png` — optional listing screenshot

## Install locally
1. Open `chrome://extensions`
2. Enable Developer mode
3. **Load unpacked** → this folder

## Chrome Web Store tips
- Upload this folder as a **Theme** (not Extension)
- Use branding icons from `../branding/theme/` in the store listing form
- Do not zip extra extension files into the theme package
