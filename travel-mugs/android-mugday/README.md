# MugDay

Offline reusable-cup tracker. Log travel mug uses versus disposable cups and see a simple weekly count.

## Features

- One-tap “Used travel mug” / “Disposable cup”
- Optional drink label
- Today and last-7-days totals
- Recent log with delete
- Local Room persistence

Choosing cups for a commute kit or event? See [branded travel mugs for event marketing](https://www.gopromotional.co.uk/branded-products/travel-mugs).

## Build

```bash
cd travel-mugs/android-mugday
./gradlew assembleRelease bundleRelease
```

Package ID: `uk.co.softrank.mugday`
